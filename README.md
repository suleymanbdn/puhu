# Zaman Yönetimi

Flutter ile geliştirdiğim basit bir zaman yönetimi uygulaması.

## Ne işe yarıyor?

- Günlük görevlerini ekleyip takip edebilirsin
- Pomodoro tekniğiyle odaklanarak çalışabilirsin
- Takvimde görevlerini görebilirsin
- İstatistiklerle ne kadar verimli olduğunu görebilirsin

## Nasıl çalıştırılır?

```bash
flutter pub get
flutter run
```

## Kullanılan teknolojiler

- Flutter
- Riverpod (state management)
- Hive (yerel veritabanı)
- GoRouter (navigasyon)
