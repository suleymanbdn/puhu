# Zaman Yönetimi

Günlük hayatımda daha verimli olmak için Flutter ile geliştirdiğim bir uygulama. Hem görevlerimi takip edebiliyorum hem de Pomodoro tekniğiyle odaklanarak çalışabiliyorum.

## Neler yapabilirsin?

- **Görev listesi:** Yapılacakları ekle, öncelik ver, kategorize et
- **Pomodoro zamanlayıcı:** 25 dakikalık odak seanslarıyla çalış
- **Takvim:** Görevlerini takvimde gör, günlük planını yap
- **İstatistikler:** Haftalık verimliliğini takip et

## Kurulum

```bash
flutter pub get
flutter run
```

## Teknolojiler

Flutter, Riverpod, Hive, GoRouter
